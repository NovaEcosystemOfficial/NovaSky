# NovaSky

NovaSky is the personal mission control experience for Seestar S50 and Seestar S30 Pro observers.

The project is currently in product, brand, and website foundation phase. Android app development has not started yet.

## Repository Structure

```text
docs/
  Product, UX, technical architecture, roadmap, and brand foundation documents.

website/
  Static official landing website foundation.
```

## Current Status

- Product strategy approved.
- Product design direction approved.
- Brand foundation defined.
- Initial official website foundation created.
- **Mission Map Premium** — observatory-grade interactive sky map (`website/pages/mission-map.html`).
- Android implementation pending future approval.

## Website

The static landing website is located in [website](./website/).

It can be opened directly from `website/index.html` or served with any static web server.

## Principle

NovaSky is not a generic planetarium and does not claim to replace the official Seestar app. It is a premium companion experience for planning, observing, capturing, and remembering the night sky with Seestar workflows.
